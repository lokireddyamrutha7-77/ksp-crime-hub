# KSP Crime Intelligence Hub
### Team CrimeZero | Karnataka Police Datathon 2026

## Project Overview
An AI-powered Crime Intelligence Platform for Karnataka Police 
that provides real-time crime mapping, criminal network analysis, 
risk prediction, and AI-powered investigation tools.

## Live Demo
- Frontend: Coming soon (Vercel)
- Backend API: Coming soon (Render)

## Features
- Crime Intelligence Map with hotspot detection
- Criminal Network Analysis using Neo4j
- ML-based Risk Prediction Engine
- Smart Alert Center
- AI Investigator (Natural language queries in Kannada + English)
- Voice FIR Generator (speak → FIR in 30 seconds)
- Dialect AI Officer (Kannada, Tulu, Kodava, Urdu, Hindi-Kannada)
- Sketch AI Witness

## Tech Stack
- Backend: Python FastAPI
- Database: Supabase (PostgreSQL)
- AI: Groq API (Llama 3.3), Whisper STT
- Frontend: React + Tailwind + Leaflet.js
- ML: Scikit-learn, XGBoost
